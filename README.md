# Liga Robótica | 42 Málaga Fundación Telefónica

Repositorio de recursos, código y documentación sobre robótica y electrónica aplicadas al aprendizaje colaborativo, en el entorno de **42 Málaga Fundación Telefónica**.

## Tecnologías y áreas de aprendizaje

- Arduino y programación de microcontroladores.
- ESP32 y proyectos conectados.
- Raspberry Pi y prototipos.
- Electrónica, sensores y resolución práctica de problemas.
- Colaboración, documentación y aprendizaje entre iguales.

## Cómo orientarse en el repositorio

Explora los materiales y el código disponibles para identificar cada práctica y sus requisitos. Antes de ejecutar un proyecto de hardware, verifica el modelo exacto de placa, las conexiones, la alimentación y las bibliotecas necesarias.

## Qué queremos documentar mejor

Este repositorio también puede mostrar *cómo se aprende y colabora* alrededor de la tecnología. La siguiente evolución documental debería incorporar, **solo cuando existan evidencias verificables**:

1. Fichas por práctica: objetivo, componentes, esquema, código, montaje y validación.
2. Guías para nuevas incorporaciones y recomendaciones de seguridad.
3. Contribuciones individuales y referencias a materiales de terceros.
4. Retos o talleres realmente realizados, con su fecha y resultados.
5. Decisiones técnicas y aprendizajes extraídos de las actividades.

## Participación y contribuciones

Si deseas contribuir, describe la mejora que propones y su contexto, evita subir credenciales o datos de participantes y documenta las pruebas que has realizado. Antes de atribuir organización, mentoría o dirección de actividades concretas, comprobaremos la autoría y la participación efectiva.

## Sobre el perfil de este repositorio

Me interesa el vínculo entre tecnología, formación, motivación y desarrollo de personas. Este espacio está orientado a hacer más accesibles las experiencias prácticas de aprendizaje tecnológico.
